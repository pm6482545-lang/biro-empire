# Biro Empire website

Single-file site: `index.html` (styles and script inside) and the `images/` folder.

## Publish on GitHub Pages
1. Upload all files (keep the `images` folder) to a repository.
2. Go to Settings > Pages.
3. Under Source choose the `main` branch and `/ (root)`, then Save.
4. Your site appears at `https://USERNAME.github.io/REPO/`.
